# Fertilized Farmlands [2F]

A lightweight Fabric mod that keeps farmland at maximum moisture. Fabric API is not required.

[Modrinth](https://modrinth.com/project/fertilized-farmlands-2f) · [Wiki](https://github.com/gingermat24/Fertilized-Farmlands-2F/wiki) · [Issues](https://github.com/gingermat24/Fertilized-Farmlands-2F/issues)

## Downloads

| Minecraft | Download |
| --- | --- |
| 1.21.x | [fertilized-farmland-1.21.x-1.0.0.jar](dist/fertilized-farmland-1.21.x-1.0.0.jar) |
| 26.1–26.3 | [fertilized-farmland-26.x-1.0.0.jar](dist/fertilized-farmland-26.x-1.0.0.jar) |

Install the matching JAR in your Minecraft `mods` folder. Java 21 is required for Minecraft 1.21.x, and Java 25 for Minecraft 26.x.
